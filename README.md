# Portfolio — Abdullah Al Jehan

A personal portfolio site with a terminal/cyber aesthetic. Built with plain HTML, CSS, and JavaScript — no frameworks, no build step, no npm dependencies.

## Features

- Live GitHub project feed
- Interactive CLI overlay (`Ctrl+~`)
- OKLCH-based color theming
- Downloadable resume
- Contact form

## Tech Stack

HTML5 · CSS3 · Vanilla JavaScript · Hosted on GitHub Pages

## Structure

```
.
├── index.html
├── script.js
├── style.css
└── assets/
```

## Setup

```bash
git clone https://github.com/abdullahaljehan-me/portfolio.git
cd portfolio
```

Open `index.html` in a browser, or serve it locally. Personal details (GitHub username, resume, email, photo) live in `script.js` and `index.html`.
